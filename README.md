# Basic Calculator Program in C

## Description

This is a simple C program that performs basic arithmetic operations using a `switch case`.

The program can perform:

* Addition
* Subtraction
* Multiplication
* Division

The user enters two numbers and selects an operation from the menu.

---

## Features

* Uses `switch case`
* User-friendly menu
* Handles division by zero
* Simple and beginner-friendly code

---

## Technologies Used

* Programming Language: C
* Compiler: GCC / Turbo C / CodeBlocks / VS Code

---

## How to Run the Program

### Step 1: Save the Program

Save the code as:
`calculator.c`

### Step 2: Compile the Program

Use a C compiler.

Example using GCC:

```bash
gcc calculator.c -o calculator
```

### Step 3: Run the Program

```bash
./calculator
```
